# 📈 Hisse Portföyü Yönetim Uygulaması

Modern ve kullanıcı dostu bir hisse portföyü yönetim uygulaması. Borsa İstanbul (BIST) hisselerinizi takip edin, portföyünüzü yönetin ve performansınızı görselleştirin.

## ✨ Özellikler
- 📊 Gerçek zamanlı portföy dağılımı grafiği
- 💰 Toplam portföy değeri takibi
- 📱 Mobil uyumlu tasarım
- 🔄 Otomatik veri kaydetme
- 🎨 Modern ve şık arayüz
- 📈 Hisse bazında kar/zarar takibi
- 🔍 Kolay hisse arama ve ekleme
- ✏️ Hisse düzenleme ve silme
